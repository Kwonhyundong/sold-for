## scout — 매물 시장 정찰기

마이크로 인수 마켓플레이스를 긁어서 "뭐가 얼마에 팔리는지"를 데이터로 뽑는다.
외부 라이브러리 없이 파이썬 표준 라이브러리만 쓴다.

```bash
python3 -m scout.cli collect   # 수집 → data/listings.db
python3 -m scout.cli report    # 리포트
```

### 왜 스냅샷을 쌓는가

`snapshots` 테이블은 매 수집마다 한 줄씩 쌓인다. 매물이 목록에서 사라지면
`present=0` 으로 기록된다. **사라짐 = 팔렸을 가능성**이므로, 며칠 돌리면
호가가 아니라 *실제 체결*에 가까운 신호를 얻는다. 지금 공개된 건 전부
호가일 뿐이라 이게 필요하다.

### 구조

- `scout/fetch.py` — HTTP 수집 (재시도·백오프)
- `scout/parse.py` — 사이트별 파서. 자기가 읽은 값이 그 카드 안에 있는지 스스로 검증
- `scout/store.py` — SQLite 저장 + 스냅샷
- `scout/analyze.py` — 배수 계산, 파는 쪽 관점 집계
- `scout/cli.py` — 명령줄

사이트 HTML이 바뀌면 `parse.py` 만 고치면 된다.
